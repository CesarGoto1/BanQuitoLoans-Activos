Colores

Azul océano para la marca, la cabecera de los resúmenes y los enlaces. Amarillo sol solo para el botón principal, la pestaña activa y la barra de avance. Verde, ámbar, rojo y celeste comunican estado, nunca decoran.

Tipografía

DM Sans en todo el sistema (se carga desde Google Fonts en index.html). Cinco tamaños y no más. Los montos usan números de ancho fijo para que las columnas cuadren.

Cómo usarlo

El CSS ya está importado en main.jsx y la fuente DM Sans en index.html, así que las clases funcionan en cualquier componente. El logo está en public/logo-bq.png. No se escriben colores ni tamaños a mano: si hace falta un color en un CSS propio, se usa la variable.

import './styles/banquito.css'

.mi-resumen { border-color: var(--bq-borde); color: var(--bq-primario); }
